# План улучшений (сравнение с конкурентами)

Продуктовые идеи, накопленные при сравнении SiliconSense с другими Suno-промпт-инструментами.
Технические/security-проблемы — см. [AUDIT.md](AUDIT.md), это отдельный список.

## Из сравнения с suno-complier.netlify.app (2026-09-28)

- [ ] **Явная привязка вывода конструктора к полям Suno.** В блоке готового промпта (вкладка
  «Конструктор») подписать явно, что куда вставлять: "→ Вставить в поле Style" / "→ Вставить в
  поле Lyrics", как у конкурента. Сейчас у нас просто один текст с промптом.
- [ ] **Шпаргалка по слайдерам Suno Custom Mode.** Рядом с готовым промптом выводить рекомендованные
  числовые значения для Advanced Options в самом Suno: Duration, Weirdness, Style Influence,
  Audio Influence — по аналогии с блоком "РЕКОМЕНДАЦИИ ПО СЛАЙДЕРАМ" у конкурента. Дёшево сделать,
  закрывает разрыв «промпт готов» → «что руками выставить в интерфейсе Suno».
- [ ] **Шеринг-ссылка на конфигурацию конструктора.** Закодировать выбранные чипы/слайдеры в
  URL (query/hash), чтобы можно было переслать ссылку без аккаунта и без экспорта JSON.
- [ ] **Лёгкий guided-режим / quick start** поверх текущего дашборда из 9 вкладок + AI Lab —
  один экран с 3–4 шагами (стиль → вокал → текст → готово) с постоянно видимым live-превью
  промпта, для новых пользователей. Мощный режим (каталог, AI Lab) остаётся как «продвинутый».
- [ ] Проверить производительность рендера длинного каталога (811 карточек) на слабых
  устройствах/мобильных — при автоматизированном скролле были заметны подвисания кадра
  (не подтверждено как баг сайта, возможно артефакт тестового браузера, но стоит перепроверить).

## Из сравнения с siliconsense.club (оригинал, с которого сделан клон) — 2026-09-28

Важный контекст: siliconsense.club — это оригинал, с которого сделан наш клон (см. README).
Он сильно ушёл вперёд: 1164 артиста / 488 стилей (у нас 811), сотни микро-жанров в конструкторе
(вместо наших ~100), собственный лендинг, гайды, RU/EN/DE.

- [ ] **Аудио-превью прямо на карточке промпта.** У каждой открытой карточки — кнопка
  "▶ Как звучит этот промпт" с реальным 15-секундным сэмплом, сгенерированным Suno по этому
  промпту. Это сильнейший элемент доверия на их лендинге ("промпт реально работает, послушай").
  У нас превью нет вообще. Технически: заранее сгенерировать и захостить короткие сэмплы хотя бы
  для топ/бесплатных карточек.
- [ ] **Аудио-анонимайзер (бесплатный инструмент).** Suno иногда отклоняет загружаемый трек
  («уже есть в базе»); инструмент перерабатывает файл (микросдвиг питча/темпа, переэнкод,
  обрезка тишины и т.п.), чтобы фильтр пропустил. Реальная боль пользователей, у нас такого нет.
- [ ] **Подготовка русской лирики для Suno («Русские ударения»).** Расстановка ударений,
  восстановление Ё, разбивка длинных слов — чтобы Suno правильно пропевал русский текст.
  У нас нет ничего подобного, а аудитория в основном русскоязычная — сильный локальный
  дифференциатор, конкурент явно продаёт это отдельным платным пунктом Lab.
- [ ] **Prompt Optimizer.** Вставляешь свой сырой/кривой промпт — AI пересобирает его по чёткой
  структуре (эпоха → жанр → вокал → инструменты → продакшн, у них это называется "GMIV").
  Отличается от нашего Anti-Slop Filter (тот бьёт по штампам, а не по структуре/порядку) —
  скорее дополняющий, чем дублирующий инструмент.
- [ ] **Lyrics Doctor.** Не генерация лирики с нуля (как у нас), а разбор и переписывание уже
  готового пользовательского текста по рифме/плотности/структуре в стиле выбранного артиста.
  Хорошее дополнение к существующему генератору лирики.
- [ ] **Публичный лендинг перед платным доступом.** У нас сразу экран с кодом доступа. У них —
  открытая главная с бесплатными примерами карточек (с аудио), лендингом фич, отзывами, FAQ,
  разделами /guide, /methodology, /about — и только потом апсейл на полный каталог. Стоит
  добавить публичную "витрину" до код-гейта — для органического трафика/SEO и конверсии.
  Сопутствующее: у них у каждой подстраницы свой SEO-заголовок (`<title>`), у нас, похоже,
  один статичный title на всё SPA — тоже стоит поправить для отдельных маршрутов.
- [ ] **Резко расширить каталог микро-жанров в конструкторе.** У них в дропдауне "Жанр" сотни
  специфичных под-жанров (включая нишевые: cowbell-phonk, gqom, uzbek-romantic-estrada,
  caucasian-chanson и т.д.), у нас — заметно более крупная зернистость. Не обязательно бежать
  за объёмом, но стоит посмотреть на их список как источник идей для расширения.
- [ ] (Для проверки, не точная копия) Посмотреть на модель монетизации: у них не бинарный
  unlock-код, а разовая оплата 1990₽ **плюс** подписка с ежемесячными "кредитами", которые
  тратятся по инструментам Lab (разная цена за Vocal Anchor, Style Genome, Audio→Prompt и т.д.).
  Это отдельное бизнес-решение, не чисто техническая фича — обсудить отдельно, прежде чем
  что-то менять в текущей access-code модели.
