## Важное различие двух функций

- **AI Lab → ДНК-декодер трека**: анализирует загруженную песню и составляет промпт. Для этого отправляет аудиосэмплы в OpenAI API и расходует платный баланс. Саму композицию не меняет.
- **Аудиомастерская → Голос → инструмент**: создаёт новый MP3 с инструментальной партией вместо вокальной мелодии. Работает только на компьютере, где запущен локальный сервер и установлены аудиомодули.
- Песня, показанная 22 октября в ДНК-декодере как `detskaja-pust-begut-neukljuzhi.mp3`, **не обрабатывалась в Аудиомастерской**. Готовой пользовательской композиции с заменой голоса пока нет. Тестовые файлы в `C:\Temp\siliconsense-vocal-test` — только техническая проверка, не результат для пользователя.
- Результаты Аудиомастерской временные: браузер предлагает прослушать и скачать MP3, сервер удаляет временные задания примерно через 30 минут. Для постоянного хранения нажать «Скачать MP3» и выбрать папку. После перезапуска сервера список временных заданий теряется.

## Запуск на другом Windows-компьютере

1. Если используется та же флешка, открыть папку проекта на ней. Если GitHub-клон, выполнить `git clone https://github.com/Flumos1/Suno-promt.git` и перейти в папку. Установить Node.js 20.6+ и Python 3 (команда `python` должна работать в PowerShell).
2. Выполнить `npm ci`.
3. Файл `.env` на флешке остаётся локально, но **не загружается в GitHub**. Для нового клона скопировать `.env.example` в `.env` и заполнить `ADMIN_KEY`, `TOKEN_SECRET`, `OPENAI_API_KEY` своими значениями. Не публиковать ключи и не вводить их в чат. `ADMIN_KEY` в Render и локальный `ADMIN_KEY` могут отличаться.
4. Для Аудиомастерской один раз выполнить `./scripts/install-audio.ps1`. Установка Python-пакетов хранится в `%TEMP%\SiliconSenseAudio` и требуется заново на каждом компьютере.
5. Запустить `./scripts/start-audio.ps1` и держать окно PowerShell открытым. Открыть адрес из переменной `PORT` в `.env` (сейчас `http://localhost:4310/`). После перезагрузки запустить скрипт снова.
6. На первом экране ввести обычный код доступа (демо: `FREEPASS`). Затем в **AI Lab → ДНК-декодер трека** открыть доступ владельца значением `ADMIN_KEY` из `.env` *этого компьютера*. После этого открыть **Аудиомастерская**, выбрать исходный аудиофайл и инструмент, нажать «Заменить вокал», дождаться результата и скачать MP3.

Если глубокий анализ показывает `fetch failed`, проверить доступ процесса Node к `api.openai.com`: на этом компьютере ошибка возникала, когда сервер запускался в изолированной среде без внешней сети. 22 октября сервер перезапущен с сетевым доступом; проверка ключа OpenAI вернула HTTP 200. Для локальной замены вокала соединение с OpenAI не нужно.

## Секреты и файлы

- `.env` намеренно исключён из Git. Не переносить его через публичный репозиторий. Если переносите физическую флешку, он останется на ней; при клонировании создайте новый `.env` или передайте секреты отдельно безопасным способом.
- `node_modules/`, Python-окружение и временные аудиорезультаты в Git не хранятся.
- Исходный файл для реальной замены вокала нужно выбрать заново в Аудиомастерской; загрузка файла в ДНК-декодер его там не сохраняет.
